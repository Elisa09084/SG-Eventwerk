# SG EVENTWERK – Website

Website der Eventagentur **SG EVENTWERK** aus Osnabrück.
*out of the ordinary* – Partys, Community-Events & Konzerte.

## Technik

Gebaut mit den Grundsprachen des Webs – kein Build-Schritt nötig:

- **HTML** (`index.html`) – Inhalt & Gerüst
- **CSS** (`css/style.css`) – Design (dunkles Lila, Peach/Orange-Akzent)
- **JavaScript** (`js/main.js`) – Menü, Einblend-Animationen

## Ordnerstruktur

```
sg-eventwerk/
├── index.html
├── css/style.css
├── js/main.js
├── bilder/
│   ├── logo.svg          # Logo (dunkler Hintergrund)
│   ├── logo-light.svg    # Logo (heller Hintergrund, Druck/Social)
│   ├── logo-header.svg   # Logo für die Kopfzeile (ohne Slogan)
│   ├── party-hero.jpg    # Hintergrundbild Startbereich
│   ├── person-links.jpg  # Foto Gründerin 1
│   └── person-rechts.jpg # Foto Gründerin 2
└── README.md
```

## Lokal ansehen

Im Projektordner einen kleinen Webserver starten und dann
`http://localhost:8000` im Browser öffnen:

```bash
python3 -m http.server 8000
```
